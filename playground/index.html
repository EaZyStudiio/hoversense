DX Architectural Analysis & Edge Cases

BIG WIN

60fps GPU Hardware Execution

The original implementation called setHoveredProject on every continuous frame, causing React to reconcile and re-render 50 DOM nodes at 60fps. The DX architecture writes directly to --hs-strength, offloading scale and shadow rendering to the GPU compositor thread with zero React re-renders.

EDGE CASE 1

Secondary Glitch Side-Effects (GSAP Queuing)

The Conflict: In the original code, hovering a card triggered a CRT glitch animation on a separate preview terminal monitor. When scrolling fast, 10 animations queued simultaneously.

How DX Solves It: Decoupling continuous styling from discrete events. Continuous card scaling runs in CSS at 60fps, while heavy secondary side-effects (sound effects, terminal glitches) only subscribe to discrete latch events (phase === 'engaged').

EDGE CASE 2

Mobile Portrait Peek with Hidden Images

The Conflict: Mobile cards keep the preview photo hidden until hovered. If using pure CSS variables, the image tag must already exist in the DOM.

Resolution: The peek container uses max-height: calc(var(--hs-strength, 0) * 180px) and opacity: var(--hs-strength, 0). For bandwidth-heavy apps requiring lazy DOM mounting, developers can gate rendering on strength >= 0.70.

BIG WIN

Automated Touch Hygiene

The Problem: Mobile Safari and Chrome default to text selection and 500ms long-press menus. Without strict hygiene, dwelling for 320ms opens the iOS action sheet.

Resolution: createHoverSenseContainer automatically sets touch-action: pan-y, strips -webkit-touch-callout, and disables selection callouts while preserving native vertical scroll.

EDGE CASE 3

Asymmetric 2x3 Staggered Columns

The Conflict: When Column 2 is offset by 180px, items in adjacent columns do not align horizontally. Naive row-based hover triggers Column 2 prematurely.

Resolution: HoverSense measures physical viewport bounding boxes on every frame. Setting rowSplit: 1.0 treats columns independently, ensuring each card highlights only when its physical center crosses the gaze anchor.

TRADE-OFF / DOWNSIDE

Mental Model Shift

Developers accustomed to writing purely reactive JSX ({isHovered && <ActiveBadge />}) must learn to let CSS variables drive continuous state, reserving component state for discrete milestones.
